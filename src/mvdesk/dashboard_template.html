Hypothetical P&L of the static book. Every red marker is a day when the loss was bigger than the model's VaR forecast. Drag on the chart to zoom; double-click to reset.

Basel traffic light

Exceptions in the trailing 250 trading days at 99%. Five or more puts the model in the Yellow zone and raises the capital multiplier; ten or more is Red.

Exceptions by year

Count of 99% VaR breaches. About 2.5 a year is expected.

Validation scorecard

Kupiec tests the exception rate, Christoffersen tests whether breaches bunch together, Z2 tests expected shortfall. RAG: Green p ≥ 0.05, Amber 0.01–0.05, Red p < 0.01.

Findings register

Generated from the test results on every run, so the evidence always matches the numbers above.

Stress windows

Exceptions per model inside each crisis, against the number a correct 99% model would produce. Red is four or more times the expected count.

Challenger benchmarking

Mean quantile loss at 99% (lower is better) and a Diebold-Mariano test against the model under review.
